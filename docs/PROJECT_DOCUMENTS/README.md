# Project documents

Six documents that describe Hivelet as it runs today, written on 7 October 2026 from the code, the
live database's catalogue and the manuscript. Hand these to anyone joining the project, or to Claude,
before they change anything.

| # | Document | Answers |
| :--- | :--- | :--- |
| 1 | [Product requirements](01_PRODUCT_REQUIREMENTS.md) | What it does, feature by feature, and what it does not do |
| 2 | [Technical requirements](02_TECHNICAL_REQUIREMENTS.md) | The tools and versions it is built on, and the rules for changing it |
| 3 | [App flow](03_APP_FLOW.md) | Every page, and what happens on each click |
| 4 | [Design brief](04_DESIGN_BRIEF.md) | Colours, fonts, layout and words, so every screen stays on brand |
| 5 | [Data schema and access](05_DATA_SCHEMA_AND_ACCESS.md) | Where the client's data lives and who can see it |
| 6 | [Implementation plan](06_IMPLEMENTATION_PLAN.md) | What was built and in what order, and what gets built next |

These summarise; the detailed authorities stay where they are: `docs/02_BUSINESS_RULES.md`,
`docs/03_REQUIREMENTS.md`, `docs/04_ARCHITECTURE.md`, `docs/DESIGN_GUIDELINE.md`,
`docs/SCREEN_CONTRACT.md`, and the live database itself. When a fact changes, change it in the
authority and in the matching document here.

# Re-run of the Appendix L test cases, 4 November 2026

**Date:** 4 Nov 2026. **Code:** main at commit `736ec4c9` (after the UI redesign). **Cases:** the 114 rows of
`FINAL/appendices/APPENDIX_L_TEST_CASES.md` (Parts A, T, P, C, O, S, CO, PF, N). Nothing was written to the
live database; no file other than this one was changed.

## How each means works

- **Suites.** `npm run check:all` once, with the backend up and `credentials/creds.txt` present, so all 21
  suites ran. Result: **All 21 suites green** (summary table read, not the tail). `check:liveness` ran 9
  checks and printed one `note:` (no "PN/mo" headline on the public page, nothing to compare), so nothing
  was skipped. `check:api`: 78 passed, 0 failed, one SKIP (no other tenant's ticket to probe with; the 404
  for a ticket that does not exist passed). `check:concurrency` printed two `note:` lines: a receipt with
  no number, or an acknowledgement receipt, sent twice at the same instant saves twice, which the index
  exempts on purpose (B-105).
- **Refused API probes.** Unauthenticated calls to localhost:5000. Every admin, tenant and account endpoint
  tried (20) answered 401 UNAUTHENTICATED; a made-up token also 401. An empty inquiry and a bad one were
  refused 422 with field messages; a wrong reference code and phone answered 404 "No inquiry matches
  that...". Refused requests write nothing. Public reads: `/public/rooms` (33 rows, 5 clusters, no name,
  phone, email or profile field) and `/public/rates`.
- **Harness.** `_harness-admin.html` and `_harness-tenant.html` (mocked session; unmocked `/api/` calls are
  refused). Run on `127.0.0.1:5173`, because on `localhost:5173` other tabs share its storage and a sign-out
  or a Vite reload elsewhere signed the harness out. A no-transition style was injected; results were read
  with page text. To rehearse a write, `window.fetch` was wrapped in the page and the one endpoint
  answered in the backend's response shape; the request body the screen sent was recorded.
- **Catalogue and data, read only.** Supabase `execute_sql`, SELECT only: `pg_trigger`, `pg_index`,
  `pg_proc`, and counts on `rooms`, `room_assignments`, `monthly_expense_entries`,
  `expense_property_allocations`, `room_price_history`, `audit_logs`.
- **Code reading** of the exact route or component, cited by file.
- **Production, read only.** `curl` of `https://hivelet.vercel.app`: response headers (CSP enforcing, HSTS,
  X-Frame-Options DENY, nosniff, Referrer-Policy, Permissions-Policy), `/api/health` online,
  `/api/public/rooms` 33 rows, no tenant fields.

Signing in through the browser was not attempted (blocked). Cases that need a real person, a real
phone, a real GCash payment or a real sign-in on production are marked **needs a person**, with what to do.

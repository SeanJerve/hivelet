Testing Day Test Cases, 30 September 2026

Written 2026-09-29. The test cases for the first test of Hivelet by the owner and real tenants. How to run the day is in TESTING_DAY_GUIDE.md; read that first.

How to use this file. Print it. Each case has an ID, the quality it tests (ISO/IEC 25010), the requirement it traces to (docs/03_REQUIREMENTS.md), what to do, and what should happen. Fill Result with P (pass), PH (pass with help), F (fail) or NT (not tested), and put the evidence file name in Evidence. A fail always gets a line in the defect log.

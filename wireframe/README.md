# `wireframe/` — the original static prototype, superseded

Six static files — `index.html`, `guest.html`, their CSS and JS — that were the first
visual prototype of Hivelet, before the Vue 3 application in `frontend/`.

**It is not served, not built, and not referenced by anything.** Last substantive change
2026-08-25.

It is retained as design history. Treat its content as **out of date**: it still contains
figures and names that the audits have since corrected — "32 units" (the answer is **33**)
and invented resident names that were never real tenants.

**For anything current, read `frontend/` and the artifacts in
`docs/claude_pipeline/outputs/`.** Do not quote this folder in the defense.

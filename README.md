# HIVELET Development Repository

Hivelet is a web-based apartment management and financial operations system for Fe Galang Da Silva Boarding House.

This repository is intended to be developed against the documentation in `/docs`.

## Development Rule

The AI developer must read the documentation before implementing features.

The documentation is the source of truth for:
- business rules
- workflows
- roles and permissions
- financial behavior
- room and tenant relationships
- auditability
- system scope

If a requirement is unclear, do not silently invent a major business rule. Record the uncertainty and ask for clarification.

## Recommended Development Order

1. Read `docs/01_SYSTEM_BIBLE.md`
2. Read `docs/02_BUSINESS_RULES.md`
3. Read `docs/03_REQUIREMENTS.md`
4. Read `docs/04_ARCHITECTURE.md`
5. Read `docs/05_DATABASE_DESIGN.md`
6. Read `docs/06_DEVELOPMENT_ROADMAP.md`
7. Read `docs/07_AI_DEVELOPMENT_INSTRUCTIONS.md`
8. Read `docs/09_MONTHLY_INCOME_REPORT.md`
9. Read `docs/10_MONTHLY_EXPENSES_REPORT.md`

The capstone paper should be placed in:

`docs/reference/Hivelet_Capstone_Paper.pdf`

The capstone paper provides academic context. The documentation files translate the paper and validated business decisions into implementable system requirements.

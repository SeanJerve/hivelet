# APPENDIX I: INITIAL DESIGN

The interface was prototyped directly in code (Section 3.1.1), so the initial design is the first
working version of the system, as it stood on 28 August 2026, before the first iteration. Its screens
are shown in Chapter 3, Section 3.2.2, Figures 3-6 to 3-9, in the phase they belong to, so that they can
be read with the description of the design. They differ from the system as built (Figures 4-3 to 4-7):
the first iteration removed the automatic rent increase marked beside each tenant, which the landlady
does not apply, and corrected the number of units on the public page (Appendix M, Table M-19). The
landlady's financial screens of that version are not shown, because they carry figures from her
records.
